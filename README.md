# Task 5 - Number Guessing Game

## Description

This project is a simple number guessing game created using Python.

The program generates a random number between 1 and 100.
The user continues guessing until the correct number is found.

## Objective

The objective of this task is to learn:

- Loops
- Conditional statements
- Random number generation
- User input
- Basic error handling

## Technologies Used

- Python

## How the Program Works

1. The program generates a random number between 1 and 100.
2. The user enters a guess.
3. The program checks the guess.
4. If the guess is too low, the program displays "Too low".
5. If the guess is too high, the program displays "Too high".
6. If the guess is correct, the program displays a success message.
7. The number of attempts is also displayed.

## How to Run

Open the terminal in the project folder and run:

```bash
python number_guessing_game.py
